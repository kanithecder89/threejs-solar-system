# Three.js Solar System 

An interactive 3D solar system built using Three.js showcasing rotating planets, starfield background, and smooth animations.

## Features
- 8+ rotating planets with orbital motion
- Animated starfield background
- Smooth camera controls and interactions
- Responsive layout for all devices
- Optimized performance and asset loading

## Tech Stack
HTML5, CSS3, JavaScript, Three.js

## Purpose
Built to demonstrate advanced frontend animation skills and 3D web experiences.
